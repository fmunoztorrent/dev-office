# Documentación

[English](README.md) · **Español**

Dev Team Office muestra a tus agentes de código trabajando como un equipo de desarrollo en pixel art, y les da trabajo. Empieza por la instalación; las guías profundizan en cada parte.

## Para empezar

| Guía | Qué cubre |
|---|---|
| [Instalación](installation.es.md) | Requisitos, instalar, conectar tus agentes, el primer arranque, sumar un proyecto, actualizar y resolver problemas |
| [Uso](usage.es.md) | El día a día: el monitor, la bitácora, las vistas del juego, pedirle algo al equipo, la CLI completa y las teclas |

| [Pruebas E2E](e2e.es.md) | Tus pruebas de Playwright, miradas mientras corren |
